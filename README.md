# Financial Transactions Analysis with PySpark

This project analyzes financial transactions data using **Apache Spark (PySpark)** in Jupyter Notebook.  
It demonstrates how to clean, process, and explore large-scale financial transaction datasets, and lays the foundation for fraud detection or anomaly detection.

## 📂 Project Structure
- `Bda_mini_project.ipynb` → Jupyter Notebook containing the full analysis.
- `financial_transactions.csv` → Input dataset (not uploaded to GitHub for privacy/size).
- `requirements.txt` → Required Python packages.

## 🚀 Features
- Load and clean CSV data using PySpark.
- Handle missing values and duplicates.
- Exploratory Data Analysis (EDA):
  - Transaction amount distribution
  - Time-based analysis
  - Customer/type trends
- Correlation analysis for numerical columns.
- Data visualization using matplotlib/seaborn.
